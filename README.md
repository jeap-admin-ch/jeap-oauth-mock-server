# jEAP OAuth Mock Server

jEAP OAuth Mock Server is a configurable OAuth2 / OpenID Connect mock server for local development and testing. It can
issue JWTs for service-to-service calls and UI login flows, including configurable `userroles` and `bproles` claims.
